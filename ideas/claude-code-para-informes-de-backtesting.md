# Claude Code para gestionar informes de backtesting

## 💡 La idea
Usar Claude Code (o el entorno de trabajo de Claude Code) para almacenar y organizar los informes que se van generando en cada backtesting: guardar los gráficos/imágenes de resultados de cada prueba, y automatizar la creación de reportes a partir de ellos en vez de gestionarlo todo a mano.

## 🌱 Por qué podría funcionar / potencial
- Surgió viendo [[video-claude-code-proyectos]] (uno de los vídeos pendientes que se ha retomado hoy).
- Encaja directamente con [[sistema-trading-cuantitativo]], que ya tiene planeado usar Claude Code para el "entorno de testeo + informes": diseñar el entorno que ejecuta las pruebas de validación y el generador de informes que recoge sus resultados.
- Podría ser el mecanismo concreto que le falta a esa fase: un sistema de almacenamiento/organización de los informes y gráficos de cada backtest, no solo el generador de informes en sí.
